# 💰 Python Expense Tracker

A command-line expense tracker built with Python that helps users record expenses, organize spending by category, and monitor their budget.

## ✨ Features

- 📝 **Expense Tracking:** Enter an expense name and amount.
- 🗂️ **Expense Categories:** Categorize expenses into Food, Home, Work, Fun, and Miscellaneous.
- 💾 **File Handling:** Store expenses in a CSV file for persistent recordkeeping.
- 📊 **Category-wise Summary:** Calculate spending for each expense category.
- 💵 **Budget Monitoring:** View total spending and the remaining budget.
- 📅 **Daily Budget Estimation:** Estimate the budget available per remaining day of the month.

## 🛠️ Built With

- Python 3
- `datetime` — Date and time calculations
- `calendar` — Month and day calculations
- CSV file handling — Expense storage

## 🚀 Getting Started

### Prerequisites

- Python 3 installed on your system
- A terminal or code editor

### Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/Namitha-04/expense-tracker
   ```

2. Navigate to the project folder:

   ```bash
   cd expense-tracker
   ```

3. Run the application:

   ```bash
   python expense_tracker.py
   ```

## 💻 How It Works

1. Enter the expense name.
2. Enter the expense amount.
3. Choose an expense category.
4. The application saves the expense to a CSV file.
5. View the spending breakdown, total expenses, remaining budget, and estimated daily budget.
